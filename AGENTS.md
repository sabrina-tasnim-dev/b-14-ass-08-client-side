## StudioSpace — Design Reference Guidelines

Before building a frontend component, consider these resources when relevant:

- https://uiverse.io/
- https://devmeetsdevs.com/
- https://bootcamp.uxdesign.cc/free-images-and-resources-collection-for-website-c77f2fc46ce5
- https://themeforest.net/
- https://codecanyon.net/

### Guidelines

1. Use relevant resources for design inspiration and suitable UI elements.
2. Choose references based on the current component or page.
3. Do not copy any website, template, or design exactly.
4. Create an original visual identity for StudioSpace.
5. Maintain the existing monochromatic Black, White and Ash design.
6. Support both Dark and Light themes.
7. Reuse existing components, styles and dependencies.
8. Prefer free and legally usable images and assets.
9. Do not install paid templates, external scripts or new dependencies without asking.
10. If a specific reference cannot be accessed, ask for a URL or screenshot instead of guessing.

### Design Consistency

- Maintain consistent typography, spacing, borders and buttons.
- Use high-quality creative studio photography.
- Keep all layouts responsive.
- Preserve the established design system across every page.
- Do not redesign completed components unless explicitly requested.
-Don't repeat any file or folder.

The final design must remain consistent across all pages and both Dark and Light themes.
